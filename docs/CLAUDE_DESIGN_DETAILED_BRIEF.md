# Claude Design 상세 목업 라운드 요청서

## 요청

KBO GameDay의 다음 목업 라운드에서는 “예쁜 경기 일정”이 아니라 팬의 행동을 끝까지 안내하는 제품으로 시각화해 주세요. 기존 오늘·주간·월간·경기 상세 화면을 유지하되, 아래 기능이 실제 사용 흐름에서 어떻게 보이고 눌리는지까지 표현해야 합니다.

## 제품 기능과 표기 규칙

| 기능 | 화면 표기 | 사용 행동 | 예외/신뢰 신호 |
| --- | --- | --- | --- |
| 내 팀 | 상단 팀 배지와 `LG 변경` | 팀 선택 화면에서 10개 구단 중 하나 선택 | “이 브라우저·기기에만 저장” 문구와 설정 초기화 |
| 오늘 경기 | `오늘의 경기` + 상태 배지 | 경기 카드를 눌러 상세 열기 | 예정/예매 임박/예매 중/진행/LIVE/종료/취소/연기 텍스트 병행 |
| 다음 경기 | 큰 단일 카드 | 공식 예매처 또는 상세 열기 | 상대·홈/원정·구장·시각을 한 묶음으로, 카운트다운은 보조 정보 |
| 예매 | `예매 오픈까지`, `지금 예매 가능` | 공식 예매처 링크를 새 탭으로 열기 | “예매 정보는 변동될 수 있음”, 확인 시각, 공식 링크 도메인 |
| 일정 탐색 | 월간 캘린더/주간 리스트 | 기간 이동, 오늘로 이동, 내 팀/전체/홈/원정 필터 | 모바일 가로 스크롤 금지, 날짜·경기 수를 먼저 읽을 수 있게 |
| 경기 상세 | 스코어보드 + 탭 | 요약/타자/투수 탭 전환, 공유 | 12이닝까지 수평 스크롤, 팀명과 R/H/E 고정 |
| 데이터 상태 | 상단 작은 상태바 | 갱신 시각 확인 | 지연/오류/샘플 데이터를 색상 외 텍스트와 아이콘으로 표시 |
| 공유 | 상세의 `공유` | OS 공유 또는 링크 복사 | 공유 대상 경기와 날짜가 명확해야 함 |

## 반드시 그릴 화면 6종

1. 모바일 오늘: 내 팀 다음 경기, 예매 CTA, 오늘 경기 5개, 상태 혼합
2. 모바일 예매 임박: 오픈 카운트다운·공식 링크·주의 문구
3. 모바일 주간: 7일 리스트, 빈 날짜, 원정/홈 구분, 필터
4. 모바일 설정: 팀 선택, 기기 한정 저장 안내, 초기화
5. 데스크톱 월간: 42칸 캘린더와 선택 날짜 우측 패널, 경기 초과 `+N경기`
6. 모바일 경기 상세: 12이닝 스코어보드, 요약/타자/투수 탭, 공유

## 상호작용 상태

- 첫 방문: 기본 LG를 임시 선택하되 “응원팀을 골라 맞춤화” 안내
- 팀 변경: 즉시 모든 카드·필터·다음 경기·예매 안내가 새 팀 기준으로 갱신
- 새 기기: 계정 동기화 없이 기본값으로 시작한다는 점을 숨기지 않음
- 데이터 오류: 빈 캘린더 대신 원인·마지막 성공 갱신·샘플 모드 진입을 표시
- 예매 링크 실패: 공식 예매처 재시도와 링크 도메인 확인을 함께 제공
- 경기 취소/연기: 예매 CTA 제거, 사유와 새 일정 확인 행동을 우선

## 디자인 검증 질문

1. 3초 안에 내 팀의 다음 경기와 가장 가까운 행동을 찾을 수 있는가?
2. 예매 오픈 시각이 경기 시작 시각·카드 상태와 혼동되지 않는가?
3. 색상을 볼 수 없어도 경기 상태와 홈/원정을 판별할 수 있는가?
4. 390px 화면에서 스코어보드와 CTA가 잘리지 않는가?
5. 사용자가 다른 기기에서 설정이 사라진 이유를 이해할 수 있는가?

## 구현 제약

- 로그인·계정·푸시 권한을 전제로 하지 않는다.
- 실제 데이터는 Cloudflare D1 API에서 오며, 수집 지연을 표시할 수 있어야 한다.
- 공식 예매 URL만 외부 링크로 사용한다.
- 모션은 보조적이며 `prefers-reduced-motion`을 존중한다.
