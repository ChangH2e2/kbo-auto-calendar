# KBO GameDay 제품 청사진

## 1. 제품 정의

KBO GameDay는 야구팬이 **내 팀의 경기 일정, 예매 시점, 경기 결과와 상세 기록을 한 흐름 안에서 확인하는 개인화 캘린더**다. 기존 서비스의 핵심 자산인 일정·예매·기록을 유지하되, 단순한 월간 달력이 아니라 “다음 행동을 알려주는 경기 허브”로 다시 설계한다.

### 해결하려는 문제

- 경기 일정과 예매 오픈 정보를 서로 다른 사이트에서 찾아야 한다.
- 월간 달력은 모바일에서 정보가 작고 복잡해진다.
- 예정·진행·종료·취소 경기의 상태가 한눈에 구분되지 않는다.
- 데이터가 언제 갱신됐는지, 믿을 만한지 알기 어렵다.
- 예매 오픈을 놓친 뒤에야 경기 일정을 확인하는 경우가 많다.

### 핵심 가치 제안

> 좋아하는 팀을 한 번 고르면, 다음 경기와 예매할 순간부터 지난 경기 기록까지 가장 짧은 동선으로 보여준다.

## 2. 목표 사용자

### 주 사용자: 특정 구단을 응원하는 팬

- 하루 또는 일주일 단위로 내 팀 일정을 빠르게 확인한다.
- 홈 경기 예매 오픈 시점을 중요하게 생각한다.
- 경기가 끝난 뒤 최종 점수와 간단한 선수 기록을 확인한다.

### 보조 사용자: 여러 경기를 보는 야구팬

- 오늘 열리는 전체 KBO 경기를 훑어본다.
- 월간 일정과 팀별 일정을 비교한다.
- 취소·변경된 경기 여부를 확인한다.

## 3. 제품 원칙

1. **오늘과 다음 행동 우선**: 첫 화면은 달력보다 다음 경기와 예매 상태를 먼저 보여준다.
2. **상태가 디자인을 결정**: 예정, 예매 임박, 예매 중, 진행, 종료, 취소를 색상과 문구로 일관되게 표현한다.
3. **모바일은 주간·목록 중심**: 작은 월간 칸에 정보를 억지로 넣지 않는다.
4. **데이터 신뢰성 노출**: 마지막 갱신 시각과 데이터 이상 상태를 숨기지 않는다.
5. **공식 경로 연결**: 예매 링크와 일정 출처를 명확하게 표시한다.
6. **알림은 동의 기반**: 로그인이나 알림 권한 없이도 핵심 기능을 쓸 수 있어야 한다.

## 4. MVP 범위

### A. 홈 / 오늘

- 선택한 응원팀과 전체 경기 전환
- 다음 경기 카드: 상대, 장소, 시작 시각, 선발 정보(확보된 경우)
- 홈 경기 예매 상태: 오픈 예정, 남은 시간, 예매 중, 종료
- 오늘의 전체 경기 목록
- 최근 데이터 갱신 시각 및 오류 안내

### B. 일정

- 모바일 기본: 주간 리스트
- 데스크톱 기본: 월간 캘린더
- 팀 필터, 홈/원정 필터
- 이전·다음 주/월 이동 및 오늘로 돌아가기
- 경기 상태별 표시: 예정, 진행, 종료, 취소, 연기

### C. 경기 상세

- 예정 경기: 일정, 구장, 예매 오픈 시각, 공식 예매처 링크
- 진행 경기: 현재 점수와 이닝 상태(데이터가 제공될 때)
- 종료 경기: 최종 점수, 이닝별 점수, 팀 합계, 주요 타자·투수 기록
- 취소/연기 경기: 사유 및 추후 일정 상태
- 데이터 출처와 마지막 갱신 시각

### D. 개인화

- 첫 방문 시 응원팀 선택
- 기기 로컬 저장으로 즉시 개인화
- 전체 팀 보기로 언제든 전환
- 로그인은 MVP에서 제외

### E. 운영 신뢰성

- 수집 실행 이력과 성공/실패 상태 저장
- 마지막 성공 수집 시각 표시
- 원본 응답과 정규화 데이터 분리
- 전체 삭제 후 삽입 금지; 검증된 배치 단위 upsert

## 5. MVP에서 제외

- 좌석 선택 및 결제 대행
- 커뮤니티, 댓글, 승부 예측
- 실시간 문자중계의 자체 생산
- 회원가입과 여러 기기 간 설정 동기화
- 푸시 알림 및 캘린더 구독은 2단계 이후

## 6. 핵심 사용자 흐름

### 첫 방문

1. 사용자가 응원팀을 선택한다.
2. 오늘 화면에서 다음 경기와 예매 상태를 확인한다.
3. 경기 카드를 눌러 상세 정보를 확인한다.
4. 필요하면 공식 예매처로 이동한다.

### 일정 탐색

1. 하단 내비게이션에서 `일정`을 선택한다.
2. 주간 목록 또는 월간 캘린더를 전환한다.
3. 팀/홈·원정 필터를 적용한다.
4. 경기 카드를 눌러 상세 화면으로 이동한다.

### 종료 경기 확인

1. 종료된 경기 카드를 선택한다.
2. 최종 점수와 이닝별 점수를 먼저 본다.
3. `타자` 또는 `투수` 탭에서 선수 기록을 확인한다.

## 7. 정보 구조

- 오늘
  - 다음 경기
  - 예매 상태
  - 오늘의 경기
- 일정
  - 주간
  - 월간
- 경기 상세
  - 개요
  - 스코어보드
  - 타자
  - 투수
- 설정
  - 응원팀
  - 시간대/표시 설정
  - 데이터 출처 및 서비스 상태

## 8. 경기 상태 모델

| 상태 | 조건 | 기본 행동 |
| --- | --- | --- |
| `scheduled` | 경기 시작 전 | 일정과 예매 정보 표시 |
| `ticket_soon` | 예매 오픈 전 48시간 이내 | 남은 시간 강조 |
| `ticket_open` | 예매 오픈 이후 경기 시작 전 | 예매 버튼 강조 |
| `live` | 경기 진행 중 | 현재 점수와 이닝 표시 |
| `final` | 경기 종료 | 최종 스코어와 기록 표시 |
| `cancelled` | 취소 확정 | 취소 사유 표시, 예매 CTA 제거 |
| `postponed` | 연기 확정 | 새 일정 미정/확정 상태 표시 |

상태는 프런트엔드에서 시간만으로 추측하지 않고, 수집 데이터의 공식 상태를 우선한다.

## 9. 성공 지표

- 첫 화면에서 다음 경기 확인까지 3초 이내
- 경기 상세 진입까지 최대 2번의 탭
- 예매 가능한 홈 경기에서 공식 예매처 이동률
- 데이터 수집 성공률 99% 이상
- 마지막 성공 수집 후 30분 이상 지연 시 운영 경고
- 모바일 360px 너비에서 가로 스크롤 없이 핵심 일정 확인

## 10. 단계별 로드맵

### 1단계: 신뢰 가능한 MVP

- 새 데이터베이스와 수집 파이프라인
- 오늘·주간·월간·경기 상세
- 응원팀 로컬 개인화
- 예매 링크와 갱신 상태

### 2단계: 놓치지 않는 경험

- 웹 푸시 또는 이메일 예매 알림
- iCal 구독
- 즐겨찾는 경기

### 3단계: 경기일 경험 강화

- 실시간 상태 갱신
- 선발 라인업과 주요 기록 요약
- 구장 안내 및 날씨 연동

## 11. 결정이 필요한 항목

- 서비스 이름을 `KBO GameDay`로 확정할지
- MVP에서 실시간 경기 중계를 어느 수준까지 제공할지
- 예매 정책을 운영자가 직접 관리할지, 코드로 관리할지
- 알림 기능을 1단계에 포함할지
- 공식 KBO 데이터 이용 조건과 표시 문구
